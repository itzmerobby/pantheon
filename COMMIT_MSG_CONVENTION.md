# Commit Message Convention

1. State the intent (+, -, f, r, m).

* `+` - Added a feature or a package.
* `-` - Deleted a feature or a package.
* `f` - Fixed a feature or a package.
* `r` - Major Rework.
* `m` - Miscellaneous commit.

2. State the version.
3. Follow the format below.

```commitmsg
+ v1.0.2: Added module discovery, shared errors, and Node publishing
```
